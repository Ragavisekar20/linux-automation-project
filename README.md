# Linux Automation Project

## Overview
This Project automates routine Linux administration task using a Bash scrits.

## Features
-Creates backup of system log files
-Generates system reports
-Monitors system resources
-Stores backup and report files automatically

## Project Structure
linus-automation-project/
  -backups/
  -logs/
  -monitor.sh

## Technologies Used
-Linux (Ubuntu)
-Bash scripting
-Git
-Github

## Workflow
1. Run the monitor.sh script
2. Backup system logs from /var/log
3. Generate system report
4. Save reports in logs directory
5. Save backups in backups directory
